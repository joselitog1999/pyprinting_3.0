# INSTRUCCIONES DE INSTALACIÓN RÁPIDA (Luego de git pull / git clone):
#
# 1. Crear entorno virtual:
#    python -m venv .venv
#
# 2. Activar entorno virtual:
#    - Windows (PowerShell): .\.venv\Scripts\Activate.ps1
#    - macOS / Linux (bash/zsh): source .venv/bin/activate
#
# 3. Actualizar pip e instalar dependencias:
#    python -m pip install --upgrade pip
#    pip install -r requirements.txt
#
# NOTA IMPORTANTE SOBRE 'pyqt-tools':
#   NO instale 'pyqt-tools', 'pyqt5-tools' ni 'pyqt6-tools'.
#   PyPrinting 3.0 está programado íntegramente en Python puro con PyQt6 y NO utiliza
#   archivos de interfaz (.ui) generados por Qt Designer en tiempo de ejecución.
#   Instalar pyqt-tools/pyqt5-tools rompe el entorno al forzar versiones antiguas de
#   PyQt5 que colisionan con PyQt6 en memoria. Si necesita Qt Designer, instálelo
#   de forma externa e independiente (ej. en macOS: 'brew install qt').
#
# NOTA SOBRE EJECUCIÓN EN LAPTOPS O SIN HARDWARE (macOS / Linux):
#   PyPrinting 3.0 cuenta con simulación nativa completa. En 'config.py', configure:
#   SAFE_MODE = True
#   Esto activa los mocks de hardware (DAQmx, platina PI, láseres y cámara) y permite
#   utilizar todas las suites de análisis, visualización y procesamiento sin instrumentación física.
#
# 4. Ejecutar Lanzador Principal ("Bienvenidos al printing"):
#    python main.py

# 5. Ejecutar Módulos Individuales:
#    python app.py               # Microscopio Derecho (Suite Completa)
#    python contrapropagante.py  # Microscopio Contrapropagante (Excitación Dual)
#    python camera.py            # Suite de Cámara Réflex Canon EOS (EDSDK) & Microfotónica
#    python psf_analyzer.py      # Caracterización 2D de PSF (Gaussiana / Donut LG01)

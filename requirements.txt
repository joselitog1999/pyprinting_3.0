# PYTHON
#   - PC del banco: **Python 3.11 de 64 bits, obligatorio.** pylablib 1.4.3 trae la extensión compilada
#     de la cámara Andor (pylablib/devices/Andor/utils.cp311-win_amd64.pyd) sólo para 3.11. Con otra
#     versión `from pylablib.devices.Andor import AndorSDK2Camera` falla y PySpectrum 3.0 no ve la cámara.
#   - PC de desarrollo sin hardware: sirve cualquier 3.11–3.13 en modo seguro (PYPRINTING_SAFE=1); los
#     tests usan una cámara falsa.
#
# INSTALACIÓN
#   En el banco, usar el instalador, que hace todo lo de abajo y verifica el resultado:
#       powershell -ExecutionPolicy Bypass -File tools\install\instalar.ps1
#   A mano (mismos pasos):
#       py -3.11 -m venv .venv
#       .venv\Scripts\python -m pip install --upgrade pip
#       .venv\Scripts\python -m pip install -r requirements.txt
#       .venv\Scripts\python -m pip install --no-deps pylablib==1.4.3
#
# POR QUÉ pylablib VA APARTE, CON --no-deps
#   pylablib 1.4.3 declara como dependencias pyft232 y pyqt5. pyft232 sin el driver FTDI rompe la
#   importación de pylablib con un AttributeError que pylablib no atrapa, y PyQt5 no debe convivir con
#   PyQt6. La cámara no usa ninguno de los dos. Las dependencias de pylablib que sí hacen falta están en
#   este archivo (numpy, scipy, pandas, numba, rpyc, pyvisa, pyserial, pyusb, pyqtgraph).
#
# OPCIONALES
#   requirements-opcional.txt: picasso (localización sub-píxel en la Suite de Cámara). Trae muchas
#   dependencias (streamlit, tables, PyImarisWriter, …) y sus versiones recientes exigen PyQt6 >= 6.10.2,
#   fuera de la serie fijada abajo; el código funciona sin él.
#
# NO INSTALAR 'pyqt-tools', 'pyqt5-tools' ni 'pyqt6-tools': fuerzan PyQt5, que choca con PyQt6.
#
# MODO SEGURO (sin hardware): variable de entorno PYPRINTING_SAFE=1, o la casilla del lanzador
#   (python main.py). No se edita config.py.
# ==============================================================================
